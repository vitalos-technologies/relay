## Create or edit a template

1. Open **Content library** ([/library](/library)) → **Templates** and choose the brand.
2. Select **New template** (or the edit icon on an existing one).
3. Enter a **Name**, the **Text** and optional **Tags** (comma-separated).
4. Select **Save**.

## Start a post from a template

1. Go to **Create** ([/compose](/compose)), choose the brand.
2. Pick the **Template** (instead of **Blank post**) and create the post.
3. **Result:** the post opens with the template's text as its base content. Editing the post never changes the template.

## Delete a template

Select the delete icon and confirm. *Existing posts are unaffected.*

## Limitations

- Templates hold text and tags only — no media, destinations or schedule.
- Templates belong to one brand.
