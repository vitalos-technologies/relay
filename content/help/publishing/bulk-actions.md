## Where bulk actions are available

| Page | Actions |
|---|---|
| Planner | Reschedule, Assign, Set campaign, Add tags, Remove tags, Duplicate as drafts, Archive |
| History | Duplicate as drafts, Add tags, Set campaign, Remove tags, Archive |
| Content library (media) | Add tags, Remove tags, Archive, Unarchive, Move to Trash |
| Trash | Restore |

## Steps

1. Tick the items (or **Select all on this page**). A bar appears with the count; **Clear** empties the selection.
2. Choose an action (more under **More**). Some actions need items from one brand: *Select items from one brand.*
3. Fill in the details, for example **Tags** (comma-separated), **Assignee** / **Team** (*Leave as is*, *Unassigned*),
   **Campaign** (*No campaign*), or for reschedule **Move by** and **Unit** (*Negative moves earlier. Each post keeps its
   own time zone.*).
4. Review the preview: **N will change**, **N skipped** (with the reason per item) and a one-line consequence:

| Action | Consequence shown |
|---|---|
| Reschedule | *Approval rules still apply.* |
| Archive, Move to Trash | *Nothing on networks changes.* |
| Restore | *Nothing is scheduled or published.* |
| Assign | *Access isn't extended.* (assignees need access already) |
| Duplicate as drafts | *Copies are drafts, never scheduled.* |

5. Confirm. A **Progress** list shows **Done**, **Failed**, **Skipped** and **Pending** per item; **Cancel rest** stops
   what hasn't started; **Retry** retries failures. Undo is offered where possible (for duplicates: *Undo (trash copies)*).

## Good to know

- Each item is checked again when it runs; if items changed after the preview you see *Items changed since the preview.
  Check again.*
- Your permissions apply to every item: items you can't change are skipped, never forced.
