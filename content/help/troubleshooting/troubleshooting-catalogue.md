## Access and sign-in

| Message | Meaning | Fix |
|---|---|---|
| No access / View-only access / View only | Your roles don't include this. | [Why can't I see or do this?](/help/troubleshooting/why-cant-i-see-or-do-this) |
| Two-step verification required | Sensitive action; this session hasn't used a second factor. | [Set up two-step verification](/help/account-security/set-up-two-step-verification) |
| Confirm it's you to continue | A fresh sign-in is needed (step-up). | [Why Relay asks you to verify again](/help/account-security/step-up-verification) |
| Session ended. Sign in again. | 30 minutes idle or 12 hours passed. | Sign in again. |
| No workspace yet. Ask an admin to invite you. | Your sign-in has no workspace. | [I can't sign in](/help/troubleshooting/cant-sign-in) |
| Use the invited email address / Expired. Ask for a new one. | Invitation problems. | [Invitation link doesn't work](/help/troubleshooting/invitation-link-not-working) |
| Owners only | The action affects an Owner. | Ask an Owner. |
| Your access to this post changed | Roles changed while you were working. | Reload. |

## Writing and saving

| Message | Meaning | Fix |
|---|---|---|
| Edited elsewhere / Someone else saved a newer version | Two people edited. Nothing was overwritten. | [Edit at the same time](/help/publishing/edit-at-the-same-time) |
| Saved locally / Unsaved / You're offline. Drafting only. | Not saved to Relay yet. | [Recover unsaved changes](/help/publishing/recover-unsaved-changes) |
| Unsaved copy can't be synced | You can't edit the post any more. | Copy your text, then discard. |
| This post is archived / This brand is archived | Archived items can't be changed or scheduled. | Unarchive, or use another brand. |

## Scheduling and publishing

| Message | Meaning | Fix |
|---|---|---|
| Pick a destination. / Pick a future time. | The dialog isn't complete. | Choose destinations and a future time. |
| That time doesn't exist / … occurs twice (clocks go back) | Daylight-saving change. | [Time zones and DST](/help/calendar-and-scheduling/time-zones-and-dst) |
| This brand requires approval: submit for review instead. | Review is on for the brand. | [Submit for review](/help/teams-and-approvals/submit-a-post-for-review) |
| This brand does not require approval. Schedule it directly. | No review on this brand. | [Schedule a post](/help/calendar-and-scheduling/schedule-a-post) |
| Fix the highlighted destinations or deselect them | A channel's limits or required fields fail. | [Readiness checks](/help/publishing/check-before-sending) |
| Cancel the schedule before archiving this post / This post is scheduled… Cancel the schedule first. | Live schedule. | [Reschedule, pause or cancel](/help/calendar-and-scheduling/reschedule-pause-or-cancel) |
| This post was published. Archive it instead | Published posts can't be trashed. | [Archive, trash and delete](/help/publishing/archive-trash-and-delete) |
| Publishing has already started for at least one destination | Can't move it any more. | Cancel remaining destinations. |
| Failed / Not published | The network refused it. | [Publishing failed](/help/troubleshooting/publishing-failed) |
| Unknown — needs review / Sent, not confirmed | No answer from the network. | [Resolve an unconfirmed delivery](/help/calendar-and-scheduling/retry-or-resolve-a-delivery) |
| Expired / Missed deadline / Overdue / Blocked / Paused | Didn't go out at its time. | [Post not sent on time](/help/troubleshooting/post-not-sent-on-time) |
| Needs publisher / Needs new review (Team → Held posts) | Authority hold. | [Adopt held posts](/help/teams-and-approvals/reassign-work-and-held-posts) |

## Reviews

| Message | Fix |
|---|---|
| Reset — the post changed / Invalidated — post changed | [Why an approval was reset](/help/teams-and-approvals/when-an-approval-is-reset) |
| You worked on this content, so you cannot give its independent approval. | Separation of duties; another reviewer must approve. |
| You already approved this stage. Another eligible person must approve. | Quorum needs someone else. |
| This review isn't available (client) | Share removed or guest access ended; see [Guests and client reviews](/help/teams-and-approvals/guests-and-client-reviews). |
