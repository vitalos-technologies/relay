1. In a conversation open **Customer and case → Identity**. The **Channel** identity is shown; **Customer** says
   **Not linked** if it isn't linked yet.
2. Select **Link to customer**. *Link only when you have confirmed it is the same person (for example an order number).
   Names alone are not enough.*
3. Search existing customers (**Customer name in Relay**) or create a **New customer**.
4. Fill in **How did you confirm it is the same person?** (*e.g. Same order number #1042*) and select **Link**.
5. **Result:** **Other conversations** lists this customer's conversations on other channels.

To undo, select **Unlink** and give a **Reason** (*e.g. Wrong person*). *The link history is kept.*

## Rating requests

Where the channel supports it, **Ask for a rating** sends a satisfaction request (*Rating request sent*); the answer
appears under **Satisfaction**.
